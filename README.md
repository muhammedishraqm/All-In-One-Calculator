# OmniCalc 

**The only calculator you'll ever need.** OmniCalc is a lightning-fast, offline-capable application featuring over 50 specialized calculators for finance, health, exact mathematics, and everyday utilities. 

## Key Features

Massive Library: 50+ tools ranging from SIP and EMI calculators to Quadratic Equation solvers and Password Strength checkers.
Build with AI: Can't find what you need? Describe any custom calculator, and our integrated AI will build, style, and add it to your library instantly.

Fully Offline: Perform complex calculations without relying on an internet connection.

Global Tools:Real-time currency conversion and instant time zone synchronization.

User-Centric Design: Includes a system-wide Dark Mode and a persistent History tab to track recent calculations.

## The problem this app solve 

Option 1: A punchy, one-sentence summary (Great for a "Projects" section overview)

Developed an offline-capable web application that eliminates app-switching by consolidating over 50 specialized tools—ranging from regional finance (like Indian GST and mutual fund SIP returns) to advanced academic math (statistics and probability)—and solved rigid tool limitations by integrating an AI feature to dynamically generate custom calculators on demand.

Option 2: Action-oriented bullet points (Great for detailing your experience)

Overcame rigid app limitations: Engineered a "Build with AI" feature that solves the problem of niche user needs by dynamically generating and integrating completely custom calculators via natural language prompts.

Ensured offline accessibility: Designed a fully offline-capable architecture so users can perform complex, secure calculations (like password entropy or tax estimations) without relying on an internet connection.
